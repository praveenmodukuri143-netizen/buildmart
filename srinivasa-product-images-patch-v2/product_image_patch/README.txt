Srinivasa Building Materials - Product Image Update

This patch uses the original product pictures available from the conversation and does NOT generate or edit the pictures.

Included original pictures:
- Ramco Cement
- Cement Ring Wells
- Iron Rods (used for 6mm, 8mm, 10mm, 12mm)
- Red Bricks
- Sand
- 3/4 Aggregates
- Baby Chips
- Dust

All product images are shown inside the same fixed-size frame using object-fit: contain, so they are not stretched or distorted.

Cement Varra is mapped to assets/products/cement-varra.png. The original Cement Varra image was not available as a standalone file in the current workspace, so add that original file there when available.

How to apply:
1. Copy the contents of this patch folder into the root of the existing buildmart repository (where index.html and script.js are).
2. Run PowerShell:
   .\apply-product-images.ps1
3. Check the website locally.
4. Then git add, commit, and push.
